# مجلد صور المقالات — القاعدة الوحيدة لصور المحتوى

كل صور المقالات تعيش هنا فقط: `blog/assets/images/articles/`.
لكل مقال فولدر باسم الـ slug الخاص به (نفس slug ملف الـ markdown في `content/ar/` و`content/en/`).

```
blog/assets/images/articles/
├── README.md                      ← هذا الدليل
├── adsense-road-01-foundations/
│   ├── cover.png                  ← غلاف المقال (إلزامي إن أُعلن عنه في front matter)
│   └── img-01.webp …              ← الصور الداخلية (ترقيم تسلسلي)
├── adsense-road-02-content-plan/
│   └── cover.png
└── <slug>/
    ├── cover.png
    └── img-NN.webp
```

## قواعد التسمية (المولّد يفرضها)

| العنصر | القاعدة |
|---|---|
| اسم فولدر المقال | نفس الـ slug حرفيًا: أحرف لاتينية صغيرة وأرقام وشرطات فقط |
| الغلاف | `cover.png` أو `cover.webp` — مقاس 1200×675 (نسبة 16:9) |
| صور داخلية | `img-01.webp`، `img-02.webp` … بالترتيب |
| الصيغ المسموحة | `png` · `webp` · `jpg` · `jpeg` · `svg` |
| الوزن المستهدف | ≤ 150KB لكل صورة (webp مفضّل للداخلية) |

## كيف تربط الغلاف بالمقال

أضف سطرًا في front matter ملف المقال (عربي وإنجليزي بنفس المسار):

```markdown
---
title: "…"
description: "…"
date: 2026-10-24
category: adsense
cover: "/assets/images/articles/adsense-road-01-foundations/cover.png"
---
```

- المولّد (`scripts/generate.mjs`) يرفض البناء إذا أُعلن `cover` وملفه غير موجود على القرص — لا صور مكسورة أبدًا.
- الغلاف يظهر تلقائيًا: أعلى المقال، وفي مصغّرات البطاقات (الرئيسية/الأرشيف/التصنيف)، وفي وسم `og:image` للمشاركة.

## كيف تدرج صورة داخل نص المقال

بصيغة markdown العادية بمسار مطلق يبدأ بـ `/assets/`:

```markdown
![وصف واضح لما تُظهره الصورة](/assets/images/articles/adsense-road-01-foundations/img-01.webp)
```

- النص البديل (alt) إلزامي ووصفي — يكتب بالعربية في المقال العربي وبالإنجليزية في الإنجليزي.
- الصور تُحمّل بـ `loading="lazy"` تلقائيًا.

## حدود يجب الالتزام بها

1. صور من صنعك أنت فقط أو مرخّصة للاستخدام — لا سحب صور من مواقع أخرى (hotlinking).
2. لا صور تحتوي أرقام أرباح أو لقطات لوحات تحكم حقيقية إلا إن كانت لك فعلًا.
3. لقطة شاشة لأداة مسموحة — لكن اذكر مصدرها في نص المقال.
4. لا تُدرج صورًا في صفحات القانونية أو 404 — المجلد للمقالات حصرًا.
